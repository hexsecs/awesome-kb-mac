# Developer Tools / Network Analysis

- [Charles](charles.md) — HTTP proxy/monitor to view HTTP and HTTPS traffic.
- [James](james.md) — Open-source proxy tool for checking and mapping requests with http as well as https.
- [Little Snitch](little-snitch.md) — Network monitor with a world map for visualizing network connections.
- [mitmproxy](mitmproxy.md) — Interactive intercepting HTTP proxy for penetration testers and software developers.
- [Proxie](proxie.md) — HTTP debugging proxy.
- [Proxyman](proxyman.md) — Modern and intuitive HTTP debugging proxy for macOS.
- [Rockxy](rockxy.md) — Open-source HTTP(S) debugging proxy for intercepting, inspecting, modifying, and replaying requests.
- [Sniffnet](sniffnet.md) — Application to comfortably monitor your network traffic.
- [Tracexy](tracexy.md) — Open-source, session-based network intelligence for capturing live traffic and investigating PCAP/PCAPNG files locally.
- [WiFi Lens](wifi-lens.md) — Native open-source Wi-Fi analyzer and network diagnostics app with real-time spectrum scanning, channel congestion visualization, and BLE device tracking.
- [Wireshark](wireshark.md) — The world’s foremost and widely-used network protocol analyzer.
- [Apidog](apidog.md) — All-in-One workspace for API Design, Documentation, Debug, Mock, Test.
