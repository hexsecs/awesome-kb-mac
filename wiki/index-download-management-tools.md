# Download Management Tools

- [aria2](aria2.md) — Lightweight multi-protocol & multi-source command-line download utility.
- [Arroxy](arroxy.md) — Open-source yt-dlp GUI for downloading video, audio, playlists and subtitles from YouTube and other supported sites.
- [Downie](downie.md) — Video downloader for macOS with support for YouTube and other 1200 sites.
- [Deluge](deluge.md) — Deluge is a lightweight, Free Software, cross-platform BitTorrent client.
- [FOLX](folx.md) — Free download manager for Mac OS X with a true Mac-style interface.
- [Free Download Manager](free-download-manager.md) — A powerful, easy-to-use, and completely free download accelerator and manager.
- [Harbor](harbor.md) — Open-source download manager for HTTP(S), magnet links, and .torrent files.
- [JDownloader](jdownloader.md) — Open-source download manager for links, files, and hosted content.
- [Motrix](motrix.md) — Download manager for HTTP, FTP, BitTorrent, magnet links, and more.
- [Neat Download Manager](neat-download-manager.md) — Lightweight download manager with an optimized transfer engine.
- [Prism](prism.md) — Open-source download manager that splits files into parallel connections, catches browser downloads, and saves videos.
- [qBittorrent](qbittorrent.md) — A project aims to provide an open-source software alternative to µTorrent.
- [Shandian](shandian.md) — Native download manager that handles magnet links, torrents, HTTP files and videos from YouTube, Bilibili, Douyin and Xiaohongshu in one window, with…
- [Shuttle](shuttle.md) — Easy Download Manager for any links.
- [Swads](swads.md) — Synology Download Station Client, modern, native, and intuitively redesign.
- [TBD](tbd.md) — Open-source YouTube video and audio downloader built on yt-dlp, which a phone on the same Wi-Fi can also drive.
- [Transmission](transmission.md) — Fast, easy, free BitTorrent Client.
- [XGetter](xgetter.md) — Media downloader for video and audio from major websites.
- [You-Get](you-get.md) — Tiny command-line utility to download media contents (videos, audios, images) from the web.
- [youtube-dl](youtube-dl.md) — Command-line program to download videos from YouTube.com and other video sites
