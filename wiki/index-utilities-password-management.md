# Utilities / Password Management

- [1Password](1password.md) — Cross-platform password management tool.
- [Bitwarden](bitwarden.md) — Open source password management tool for Mac OS, iOS and browsers.
- [Buttercup](buttercup.md) — The Password Manager You Deserve
- [Dashlane](dashlane.md) — Cloud-based password manager with award-winning design.
- [Enpass](enpass.md) — Cross-platform password management tool with cloud integration.
- [Keyzer](keyzer.md) — Simple password manager that supports saving portable password files.
- [Keeweb](keeweb.md) — Free, cross-platform password manager compatible with KeePass.
- [KeepassXC](keepassxc.md) — Free, open source, cross-platform password manager.
- [MacPass](macpass.md) — Open-source KeePass Mac OS client.
- [Mactokio](mactokio.md) — Native TOTP/HOTP authenticator that imports accounts by webcam QR scan and keeps secrets AES-256 encrypted on device.
- [NotchOTP](notchotp.md) — Native TOTP authenticator with a notch-sized panel, keyboard shortcuts, and local Keychain storage.
- [SafeInCloud](safeincloud.md) — Cross Platform password management, low cost app!
- [Strongbox](strongbox.md) — KeePass-compatible password manager with Password Safe support.
- [Swifty](swifty.md) — Free Offline-first Password Manager for MacOS, Windows and Linux.
