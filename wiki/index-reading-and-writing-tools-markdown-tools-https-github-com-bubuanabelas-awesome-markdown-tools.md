# Reading and Writing Tools / Markdown Tools [](https://github.com/BubuAnabelas/awesome-markdown#tools)

- [Archimedes](archimedes.md) — Native macOS Markdown editor geared toward mathematical writing with inline LaTeX support.
- [Edmund](edmund.md) — Minimal, native macOS Markdown editor with live preview; works with your existing files, no vault. [](https://github.com/I7T5/Edmund)
- [EME](eme.md) — Open-source Markdown editor with an interface like Chrome.
- [iA Writer](ia-writer.md) — Writing app with an emphasis on simplicity and design.
- [Imark](imark.md) — Open-source Markdown reader that stores your comments inside the document itself as HTML comments. [](https://github.com/migsilva89/imark)
- [JustMD](justmd.md) — Open-source Markdown editor for local files that hides syntax outside the line being edited. [](https://github.com/yuraist/just-md)…
- [MacDown](macdown.md) — Open source Markdown editor for macOS with live preview and HTML/PDF export. [](https://github.com/MacDownApp/macdown)
- [Marked 2](marked-2.md) — This is the Markdown preview with an elegant and powerful set of tools for all writers.
- [MarkText](marktext.md) — Next generation markdown editor, running on platforms of MacOS Windows and Linux. [](https://github.com/marktext/marktext)
- [MarkViewer](markviewer.md) — Markdown viewer and editor for macOS with AI-assisted editing.
- [Marp](marp.md) — Markdown presentation writer with cross-platform support. [](https://github.com/marp-team/marp)
- [Marxico](marxico.md) — Delicate Markdown editor for Evernote. Reliable storage and sync.
- [MDViewer](mdviewer.md) — Fast Markdown viewer with live reload, Quick Look previews, Mermaid, math and optional AI summaries with your own or a local model.…
- [MWeb](mweb.md) — Pro Markdown writing, and static blog generator App.
- [Obsidian](obsidian.md) — A second brain, for you, forever.
- [Pixley Reader](pixley-reader.md) — Reader for Markdown specs, docs, and changelogs generated by AI tools. [](https://github.com/Applacat/PixleyReader)…
- [Scratch](scratch.md) — Lightweight, offline-first markdown notes app with WYSIWYG editing and local AI agent support. [](https://github.com/erictli/scratch)
- [Splat](splat.md) — Native macOS Markdown editor in Rust where both the source and the live preview are editable. [](https://github.com/sventmueller/splat)
- [Textus](textus.md) — WYSIWYG Markdown editor with math, tables, Mermaid and an optional AI writing assistant that works with cloud or local models.…
- [Typora](typora.md) — Truly minimal Markdown editor featuring seamless live preview.
- [Ulysses](ulysses.md) — The Ultimate Writing App for Mac, iPad and iPhone.
- [Zettlr](zettlr.md) — A markdown editor for the 21st century. [](https://github.com/Zettlr/Zettlr)
