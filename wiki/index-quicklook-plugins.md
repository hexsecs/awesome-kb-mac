# QuickLook Plugins

- [CSV Quick Look](csv-quick-look.md) — Quick Look extension for CSV and TSV files with virtual scrolling, sorting, filtering, and dark mode.
- [QLMarkdown](qlmarkdown.md) — Quick Look extension for Markdown files.
- [FluxMarkdown](fluxmarkdown.md) — Quick Look extension for Markdown previews with Mermaid, KaTeX, GFM, TOC, and charts.
- [Folderglass](folderglass.md) — Quick Look extension for folders: real size including subfolders, file-type breakdown, largest and newest files, git branch and status, and the README…
- [markdown-quicklook](markdown-quicklook.md) — Quick Look plugin for rendered Markdown previews with syntax highlighting.
- [MD QuickLook](md-quicklook.md) — Native Quick Look extension for Markdown with syntax highlighting, math, and Mermaid diagrams, without a web engine.
- [Torrent Preview](torrent-preview.md) — Quick Look extension for previewing .torrent files, trackers, and metadata.
- [quick-look-plugins](quick-look-plugins.md) — List of useful Quick Look plugins for developers
- [Syntax Highlight](syntax-highlight.md) — Quick Look extension for highlight source code files.
