# Remote Login Software

- [AnyDesk](anydesk.md) — Provides remote access across multiple machines.
- [ClawTank](clawtank.md) — Open-source RDP server for connecting to a Mac from standard Remote Desktop clients like Windows App and mstsc.
- [Glass](glass.md) — Low-latency remote desktop for Mac and Linux that you view from any browser, with nothing to install on the viewing device.
- [HopToDesk](hoptodesk.md) — Open-source remote desktop and remote support tool with end-to-end encrypted sessions.
- [MoonProxy](moonproxy.md) — GUI desktop client for FRP that puts local services on the internet with one click.
- [Moonlight](moonlight.md) — GameStream client for PCs (Windows, Mac, Linux, and Steam Link).
- [Parsec](parsec.md) — Low-latency remote desktop and game streaming tool.
- [RealVNC](realvnc.md) — The original and best software for remote access across desktop and mobile.
- [RoyalTSX](royaltsx.md) — Remote connection manager for multiple protocols.
- [RustDesk](rustdesk.md) — Yet another remote desktop software.
- [Steam Link](steam-link.md) — The Steam Link app allows you to play your Steam games across all your computers.
- [Sunshine](sunshine.md) — Self-hosted game stream host for Moonlight.
- [TeamViewer](teamviewer.md) — Remote support and screen sharing tool.
- [Windows App](windows-app.md) — Connect to a remote PC or virtual apps and desktops made available by your admin.
