# Developer Tools / Frameworks For Hybrid Applications

- [AppJS](appjs.md) — Lightweight JavaScript UI library for creating mobile webapps that behave like native apps.
- [DMG Maker](dmg-maker.md) — DMG creation tool with polished visuals and CLI support.
- [create-dmg](create-dmg.md) — Create a good-looking DMG for your macOS app in seconds.
- [Rilmazafone](rilmazafone.md) — Design DMG installers on a WYSIWYG canvas and build exactly what you drew, no scripts.
- [Electrino](electrino.md) — Desktop runtime for web apps using the system's browser engine.
- [Electron](electron.md) — Build cross platform desktop application with JavaScript, HTML and CSS.
- [ionic](ionic.md) — Build native and web apps with Angular and open web technologies.
- [MacGap](macgap.md) — Lightweight JavaScript API for OS X integration.
- [nw.js](nw-js.md) — Build desktop apps with HTML and JavaScript.
- [Qt](qt.md) — Cross-platform application framework.
- [React Native for Ubuntu](react-native-for-ubuntu.md) — Build Ubuntu desktop apps using React Native.
- [React Native macOS](react-native-macos.md) — Build OS X desktop apps using React Native and Cocoa.
- [react-desktop](react-desktop.md) — React UI Components for macOS Sierra.
- [ReactXP](reactxp.md) — Microsoft platform for Web, iOS, Android, and Windows UWP.
- [Tauri](tauri.md) — Create small, fast, secure, cross-platform applications
