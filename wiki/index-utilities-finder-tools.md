# Utilities / Finder Tools

- [Command X](command-x.md) — Cut and paste files in Finder.
- [Default Folder X](default-folder-x.md) — Quick access to your files and folders in every app.
- [FileMinutes](fileminutes.md) — Find files and take actions, all in one.
- [FinderFix](finderfix.md) — Finally, a lasting solution for Finder windows size and position. .
- [FinderRight](finderright.md) — Open-source Finder extension that adds new file, open in terminal, copy path, and cut & paste to the right-click menu.
- [Findly](findly.md) — Finder-style file drawer that slides in from any screen edge with a hotkey and slides away when you switch apps.
- [SaneClick](saneclick.md) — Finder extension that adds right-click actions for file tasks, conversion, and developer tools.
- [FlowVision](flowvision.md) — RWaterfall-style Image Viewer for macOS.
- [fman](fman.md) — The first dual-pane file manager to integrate features from Sublime Text.
- [ForkLift](forklift.md) — The most advanced dual pane file manager and file transfer client for macOS.
- [Path Finder](path-finder.md) — File management app.
- [QSpace](qspace.md) — A clean and efficient Multi-view File Manager.
- [RClick](rclick.md) — Add new functionality to the macOS Finder context menu.
- [Strata Files](strata-files.md) — Open-source file manager and Finder alternative with instant search, live folder sizes, a disk usage map and dual pane.
- [SwiftyMenu](swiftymenu.md) — Finder extension for opening selected files or folders with custom app shortcuts.
- [TotalFinder](totalfinder.md) — Chrome-styled Finder substitute.
- [XtraFinder](xtrafinder.md) — Adds tabs and cut to Mac Finder.
