# Browsers

- [Brave](brave.md) — Web browser with an emphasis on privacy and speed.
- [ChatGPT Atlas](chatgpt-atlas.md) — Browser with ChatGPT built in.
- [Chrome](chrome.md) — Chrome, developed by Google
- [Chromium](chromium.md) — Open-source browser project behind Google Chrome.
- [ungoogled-chromium](ungoogled-chromium.md) — A lightweight approach to removing Google web service dependency.
- [Firefox](firefox.md) — A free and open-source web browser developed by Mozilla.
- [LibreWolf](librewolf.md) — A fork of Firefox, focused on privacy, security and freedom.
- [Helium](helium.md) — Privacy-focused Chromium browser with built-in ad blocking.
- [Lilo](lilo.md) — Native WebKit browser with Arc-style spaces, Chrome extensions, terminal tabs in the sidebar, and a built-in MCP server for AI agents.
- [Microsoft Edge](microsoft-edge.md) — Microsoft Edge, based on Chromium, but built by MS
- [Min](min.md) — Fast, minimal browser that protects your privacy.
- [Opera](opera.md) — Experience faster, distraction-free browsing with Ad blocking, and browse privately.
- [Ora](ora.md) — Open-source browser with spaces, tab management, and a vertical sidebar.
- [Orion](orion.md) — Lightweight WebKit-based browser with support for Chrome and Firefox extensions.
- [qutebrowser](qutebrowser.md) — A keyboard-driven, vim-like browser based on Python and Qt.
- [Safari](safari.md) — Native browser for Macs.
- [Stedding](stedding.md) — Open-source Arc-style browser on Chromium with Spaces, vertical tabs, pinned folders, a command bar and Arc import.
- [Tabbit](tabbit.md) — An AI-native browser that understands your context, chats with webpages, and automates tasks.
- [Tor Browser](tor-browser.md) — Privacy browser designed for anonymous web browsing.
- [Mullvad Browser](mullvad-browser.md) — Privacy browser focused on anti-fingerprinting protection.
- [Web](web.md) — Minimal AI browser for macOS, built with SwiftUI.
- [Vivaldi](vivaldi.md) — The browser that puts you in control.
- [Yalqen](yalqen.md) — Open-source Chromium browser for developers with vertical tabs, a keyboard-first command bar, built-in developer tools, and ad and tracker blocking.
- [Yandex](yandex.md) — The quick and secure browser from Yandex for computers.
- [Zen](zen.md) — A beautifully designed, privacy-focused, and feature-rich browser
