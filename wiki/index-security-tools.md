# Security Tools

- [Antivirus One](antivirus-one.md) — Security scanner for malware, adware, and web threats.
- [BlockBlock](blockblock.md) — Me: "Please alert me whenever anything is persistently installed." BlockBlock: "You got it"
- [ClearanceKit](clearancekit.md) — Policy-based file access control tool for protected paths.
- [Dylib Hijack Scanner](dylib-hijack-scanner.md) — Utility for scanning apps vulnerable to dylib hijacking.
- [fob](fob.md) — Menu bar SSH agent that keeps keys in the Secure Enclave and gates every use behind Touch ID.
- [Hey Mac](hey-mac.md) — On-device face unlock for the lock screen and privacy shields for selected apps.
- [KextViewer](kextviewer.md) — View all modules on that are loaded in the OS kernel.
- [KnockKnock](knockknock.md) — See what's persistently installed on your Mac.
- [LinkLiar](linkliar.md) — Link-Layer MAC spoofing GUI for macOS.
- [LockDown](lockdown.md) — Open-source tool for El Capitan that audits and remediates security configuration settings.
- [Lockpaw](lockpaw.md) — Menu bar screen guard for macOS — lock and unlock your screen with a hotkey.
- [MakLock](maklock.md) — Lock any macOS app with Touch ID, Apple Watch proximity, or password. Full-screen blur overlay on all monitors.
- [LuLu](lulu.md) — LuLu is the free macOS firewall that aims to block unauthorized (outgoing) network traffic.
- [MalwareBytes](malwarebytes.md) — Malware scanner and removal tool.
- [Mana Security](mana-security.md) — vulnerability management app for individuals.
- [Vulert](vulert.md) — Dependency vulnerability monitoring service for open-source packages.
- [NoxKey](noxkey.md) — Keychain-based secret manager for API keys and tokens with Touch ID.
- [OverSight](oversight.md) — Tool for monitoring microphone and webcam access.
- [ParetoSecurity](paretosecurity.md) — A MenuBar app to automatically audit your Mac for basic security hygiene.
- [PureSnitch](puresnitch.md) — Open-source application firewall with a Little Snitch-style world map, rule manager, DNS over HTTPS, and pf-based blocking, with no telemetry.
- [RansomWhere?](ransomwhere.md) — Generic Ransomware Detection.
- [Santa](santa.md) — Binary and file access authorization system.
- [Sentinel](sentinel.md) — Plain-language Mac security-settings check with a Wi-Fi device list.
- [stronghold](stronghold.md) — Easily configure MacOS security settings from the terminal.
- [Suspicious Package](suspicious-package.md) — An application for inspecting macOS installer packages.
- [swiftGuard](swiftguard.md) — Tool for protecting USB ports from unauthorized access.
- [TaskExplorer](taskexplorer.md) — Explore all processes running on your Mac with TaskExplorer.
- [TouchBridge](touchbridge.md) — Authenticate with your phone's fingerprint as a free Touch ID keyboard alternative.
- [What's Your Sign?](what-s-your-sign.md) — Finder extension for viewing a file's code-signing information.
