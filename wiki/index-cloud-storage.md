# Cloud Storage

- [Dropbox](dropbox.md) — Cloud storage and file synchronization service.
- [Arq](arq.md) — Cloud storage backup client that supports AWS, GCP, DropBox, and more.
- [Carbonite](carbonite.md) — Carbonite can protect your Mac from all of the most common forms of data loss.
- [Mega](mega.md) — Free cloud service, offers 50GB free storage.
- [NextCloud](nextcloud.md) — Actively maintained fork of ownCloud, faster and completely open-source
- [ownCloud](owncloud.md) — Cloud storage.
- [Seafile](seafile.md) — Reliable and High Speed File Sync and Share.
