# Utilities / File Organization Tools

- [AppPorts](appports.md) — Move apps to external storage while keeping working launch links in /Applications.
- [Archivator](archivator.md) — Menu bar archive tool that compresses and extracts files by dragging them onto a radial wheel.
- [BetterZip](betterzip.md) — Archive tool supports ZIP, TAR, TGZ, TBZ, TXZ (new), 7-ZIP, RAR.
- [eZip](ezip.md) — Lightweight archive tool for ZIP, RAR, 7Z, and other common formats.
- [Fileside](fileside.md) — A modern, tiling file manager with unlimited panes.
- [Folders File Manager](folders-file-manager.md) — A file manager with an expandable folder tree, similar to that of Windows Explorer.
- [Hazel](hazel.md) — Automated file organization for your Mac. Responsibly and beautifully designed.
- [Keka](keka.md) — Open-source compression and extraction tool with broad format support.
- [muCommander](mucommander.md) — Lightweight file manager with a dual-pane interface.
- [Modal File Manager](modal-file-manager.md) — Dual-pane file manager with Vim-style hotkeys and customizable extensions.
- [Oka Unarchiver](oka-unarchiver.md) — Archive utility with RAR support, batch extraction, and password-protected archives.
- [PDF Archiver](pdf-archiver.md) — Nice tool for tagging and archiving tasks.
- [Rapidmg](rapidmg.md) — 1-Click extracting apps from DMG images to the "Applications" folder.
- [Shuffle](shuffle.md) — Fast, GPU-rendered file manager and Finder alternative built in Rust.
- [The Unarchiver](the-unarchiver.md) — Unarchive many different kinds of archive files.
- [Unarchive One](unarchive-one.md) — Archive utility for extracting and compressing many common formats.
- [Marta](marta.md) — File Manager for macOS written entirely in Swift
