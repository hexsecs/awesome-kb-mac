# Developer Tools / Version Control

- [Cornerstone](cornerstone.md) — Powerful version control with a gorgeous interface.
- [Fork](fork.md) — Fast and friendly Git client for Mac.
- [Git Cola](git-cola.md) — Powerful, Fast, Lightweight and Friendly Git GUI. For those caffeine adicting users.
- [Gitbar](gitbar.md) — Open-source，display GitHub contribution statistics on your menu bar.
- [GitButler](gitbutler.md) — Change management with parallel and stacked branches, unlimited undo, agent integrations.
- [GitFinder](gitfinder.md) — Fast and lightweight Git client for Mac with Finder integration.
- [Gitfox](gitfox.md) — Commit faster, improve your code quality with superior diffs - and look good doing it.
- [GitHub Desktop](github-desktop.md) — The official GitHub GUI.
- [GitKraken](gitkraken.md) — The most popular Git GUI for Windows, Mac and Linux.
- [GitUp](gitup.md) — A simple & powerful Git client。
- [GitX-dev](gitx-dev.md) — Fork of Pieter's nice git GUI for OS X. Includes branch/tag sidebar and various fixes.
- [Hub](hub.md) — Command-line wrapper for Git that makes you better at GitHub.
- [PullBull](pullbull.md) — GitHub pull requests, issues and Projects boards in the menu bar.
- [RelaGit](relagit.md) — The elegant solution to graphical version control. Built by developers, for developers.
- [SmartGit](smartgit.md) — Git client with support.
- [SourceTree](sourcetree.md) — Free Git & Mercurial client for Windows or Mac.
- [Sublime Merge](sublime-merge.md) — Git client, from the makers of Sublime Text.
- [Changes](changes.md) — GUI Git client. Replace the Git CLI with a clear UI and AI assist.
- [teebe](teebe.md) — Native manager for Git worktrees, with live file change badges and inline diffs.
- [Tower2](tower2.md) — The most powerful Git client for Mac and Windows.
- [Vershd](vershd.md) — The free for personal use effortless Git GUI, for Windows, Mac, & Linux.
- [Versions](versions.md) — Mac Subversion (SVN) Client.
