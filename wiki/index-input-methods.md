# Input Methods

- [Kawa](kawa.md) — Better input source switcher for OS X.
- [Keyameleon](keyameleon.md) — Open-source tool that gives each physical keyboard its own input source and switches to it automatically as you type.
- [LangSwitcher](langswitcher.md) — Keyboard layout converter for mistyped text.
- [Qingjian 青简](qingjian.md) — Rust-based cross-platform Pinyin input method that displays translations in the language you are learning alongside candidate words.
- [Rocket](rocket.md) — Makes typing emoji faster and easier using Slack-style shortcuts.
- [Sidekey](sidekey.md) — Use your iPhone as a wireless keyboard, trackpad and voice input for your Mac or Windows PC over local Wi-Fi.
- [Touch Emoji](touch-emoji.md) — Emoji picker for MacBook Pro Touch Bar.
- [Type2Phone](type2phone.md) — Use Your Mac as Keyboard for iPhone, iPad & Apple TV.
- [vChewing 唯音](vchewing.md) — Chinese input method supporting Pinyin and Zhuyin with purpose-built dictionaries.
- [betterglobekey](betterglobekey.md) — Make macOS Globe key great again!
- [InputSourcePro](inputsourcepro.md) — Tool for automatically switching input sources by app or website.
