# Reading and Writing Tools / Text Editors

- [Aurora Editor](aurora-editor.md) — Lightweight Code Editor (IDE) for macOS.
- [Bootstrap Studio](bootstrap-studio.md) — A powerful desktop app for creating responsive websites using the Bootstrap framework.
- [Brackets](brackets.md) — A modern, open source text editor that understands web design.
- [CodeEdit](codeedit.md) — A lightweight, natively-built editor. Open source. Free forever.
- [CotEditor](coteditor.md) — Lightweight plain-text editor for macOS.
- [Cursor](cursor.md) — AI code editor with autocomplete, chat, and coding agent features.
- [Emacs](emacs.md) — Popular Unix-based text editor for programmers and system administrators.
- [Haystack Editor](haystack-editor.md) — Code editor with a canvas UI for better code understanding.
- [Helix](helix.md) — A post-modern modal text editor.
- [Itsypad](itsypad.md) — A tiny, fast scratchpad and clipboard manager for macOS.
- [Lapce](lapce.md) — Lightning-fast and powerful code editor.
- [LightTable](lighttable.md) — The next generation code editor.
- [LiteEdit](liteedit.md) — Fast, native macOS code editor under 1 MB — Swift and AppKit, no Electron.
- [MacVim](macvim.md) — the text editor Vim - for macOS.
- [micro](micro.md) — Modern and intuitive terminal-based text editor.
- [Neovim](neovim.md) — Vim-fork focused on extensibility and usability.
- [NeatEditor](neateditor.md) — Fast, native macOS plain-text editor for distraction-free writing.
- [Nova](nova.md) — The beautiful, fast, flexible, native Mac code editor from Panic.
- [Plain Text Editor](plain-text-editor.md) — Simple distraction-free notepad.
- [Sublime Text](sublime-text.md) — Text editor with a fast interface and plugin ecosystem. For more plugins, check Sublime Text Plugins.
- [SubEthaEdit](subethaedit.md) — Powerful editor for writing, coding, and collaboration anytime, anywhere!
- [TextMate](textmate.md) — Editor that brings Apple's approach to operating systems into the world of text editors.
- [Tot](tot.md) — Tot is an elegant, simple way to collect & edit text. It’s your tiny text companion!
- [Vim](vim.md) — An old terminal-based editor. For common plugins, check Vim Common Plugins.
- [Vimr](vimr.md) — Refined Vim Experience for OS X.
- [Windsurf](windsurf.md) — AI code editor with agentic coding, autocomplete, and MCP support.
- [Zed](zed.md) — A high-performance, multiplayer code editor from the creators of Atom and Tree-sitter.
