# Developer Tools / Virtualization

- [Docker](docker.md) — Powerful, performs operating-system-level virtualization.
- [Berthly](berthly.md) — Native GUI for Apple's container tool, with menu bar monitoring and drag-and-drop image builds.
- [Gantry](gantry.md) — Docker management client for local and SSH remote hosts with built-in MCP server support for agent workflows.
- [Cocoa-Way](cocoa-way.md) — Wayland compositor for running Linux GUI apps without a virtual machine.
- [ContainerDesk](containerdesk.md) — Native SwiftUI workspace for Apple's container runtime, with live resource monitoring and an integrated terminal.
- [GhostVM](ghostvm.md) — Virtualization tool for creating and managing isolated macOS virtual machine workspaces.
- [Mac Android Subsystem](mac-android-subsystem.md) — Run Android apps on Apple Silicon, each in its own Mac window with its own Dock icon.
- [MacVirtue](macvirtue.md) — Run free and unlimited Virtual Machines on your Mac.
- [Mocker](mocker.md) — Container manager built on Apple's Containerization framework.
- [Multipass](multipass.md) — Ubuntu VMs on demand for any workstation.
- [OrbStack](orbstack.md) — Fast, light, and simple way to run Docker containers and Linux machines on macOS.
- [Parallels](parallels.md) — Powerful, easy-to-use VM. No free upgrade for each new Mac OS.
- [Podman Desktop](podman-desktop.md) — Open-source graphical tool for managing containers and Kubernetes.
- [Rancher Desktop](rancher-desktop.md) — Container management and Kubernetes on the desktop.
- [Lima](lima.md) — Lima launches Linux virtual machines with automatic file sharing and port forwarding.
- [QEMU](qemu.md) — A free and open-source emulator and virtualizer that can perform hardware virtualization.
- [UTM](utm.md) — UTM is an easy-to-use GUI for QEMU and can run ARM64, x64 and other VMs on M1 Macs.
- [Vagrant](vagrant.md) — Tool for building and distributing development environments.
- [Veertu](veertu.md) — The lightest VM on Mac. Responsive, sandboxed & native way to run VM on your Mac.
- [Virtual Box](virtual-box.md) — Powerful x86 and AMD64/Intel64 virtualization product.
- [VMware Fusion](vmware-fusion.md) — Powerful, commercial VM developed by VMware.
