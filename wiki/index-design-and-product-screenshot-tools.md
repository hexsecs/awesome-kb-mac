# Design and Product / Screenshot Tools

- [capcap](capcap.md) — Native menu bar screenshot tool with double-tap Command capture, annotation, scrolling capture, beautify, pinning, and image-host upload.
- [CleanShot X](cleanshot-x.md) — Discover a superior way to capture your Mac's screen.
- [CloudApp](cloudapp.md) — Work at the speed of sight.
- [Dropbox](dropbox.md) — Dropbox app offers easy screenshot capturing and sharing
- [Flameshot](flameshot.md) — Powerful yet simple to use screenshot software.
- [Glint](glint.md) — Open-source screenshot tool that finds and pixelates emails, IBANs, card numbers, and API keys on-device before you share.
- [Lightshot](lightshot.md) — The fastest way to take a customizable screenshot.
- [macshot](macshot.md) — Screenshot and annotation tool with screen recording, scrolling capture, and OCR.
- [Photon](photon.md) — Open-source screenshot, markup and screen recording tool for macOS and Windows, with no network code.
- [Scap](scap.md) — Screenshot annotation and canvas tool with blur, mosaic, and watermark features.
- [Screenshots](screenshots.md) — Open-source menu bar tool for screenshots, scrolling capture, OCR, annotation, pinning, and MP4 or GIF screen recording, with no network code.
- [Shottr](shottr.md) — Screen capture application with features like Scrolling capture, OCR and markup.
- [Shutterbar](shutterbar.md) — ShareX-style screenshots with ⌘C-to-clipboard, after-capture tasks, last-region recapture and scrolling capture.
- [Sitch](sitch.md) — Skitch-style screenshot annotation with tapered arrows, blur, and pixelate, fully offline.
- [Skitch](skitch.md) — Screen capture application with a powerful annotation capabilities.
- [Snappy](snappy.md) — Open-source, Ubuntu-style screenshot tool with an adjustable selection, window and full-screen capture, markup, blur, and text copying.
- [Snapzy](snapzy.md) — Free and open-source native macOS app for screenshots, screen recording, annotation, and video editing.
- [Snip](snip.md) — Application for sharing captured images on QQ Mail.
- [Snipaste](snipaste.md) — Simple but powerful snipping tool.
- [Teampaper Snap](teampaper-snap.md) — Let your screenshots speak up.
- [Tuji](tuji.md) — Take a screenshot, annotate it, and beautify it.
- [Xnip](xnip.md) — Handy Screenshot App.
