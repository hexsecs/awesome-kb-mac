# Translation Tools

- [DeepL](deepl.md) — Best quality translations
- [Easydict](easydict.md) — A concise dictionary and translator for looking up words and translating text.
- [Grammarly](grammarly.md) — Refine your english
- [iTranslate](itranslate.md) — Translation app for text and web pages in multiple languages.
- [Live Translator](live-translator.md) — Real-time on-screen translation of any system audio (YouTube, podcasts, meetings) using OpenAI or Gemini.
- [Ludwig](ludwig.md) — Linguistic search engine that helps you to write better in English.
- [Mate Translate](mate-translate.md) — Translate in Safari and any app on macOS between 103 languages.
- [MoePeek](moepeek.md) — Translation tool with text selection, OCR, clipboard, and manual input support.
- [Nani](nani.md) — Fast AI translation with explanations.
- [OpenAI Translator](openai-translator.md) — Translation app and browser extension powered by AI models.
- [ScreenTranslate](screentranslate.md) — Capture any area or select text to translate instantly, fully on-device.
- [SwaprTrans](swaprtrans.md) — Lightweight (<2MB) native menu bar tool for select-and-space translation and in-place Enter rewrite, powered by Apple's on-device model.
- [Tercana](tercana.md) — Menu bar companion for PS5 Remote Play: live on-device subtitle translation into any language, plus a PSN trophy tracker.
- [Translate Like Me](translate-like-me.md) — Open-source menu bar translator that replaces the selected text in any app, in your own writing style, via Claude, ChatGPT or Grok.
- [Translatium](translatium.md) — Translation app for words, phrases, and images in 100+ languages.
