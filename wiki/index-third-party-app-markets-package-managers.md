# Third Party App Markets / Package Managers

- [Applite](applite.md) — User-friendly GUI app for Homebrew Casks. Install, update, and uninstall apps with a single click.
- [Cork](cork.md) — An intuitive and complete Homebrew GUI written in SwiftUI that supports all Homebrew features.
- [Homebrew](homebrew.md) — The missing package manager for macOS.
- [MacPorts](macports.md) — Package manager for installing and maintaining open-source software.
- [MacUpdate Desktop](macupdate-desktop.md) — Simplifies finding, buying and installing apps for your Mac.
