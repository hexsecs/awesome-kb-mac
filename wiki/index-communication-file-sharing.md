# Communication / File Sharing

- [Cyberduck](cyberduck.md) — Free FTP, SFTP, WebDAV, S3, Backblaze B2, Azure and OpenStack Swift browser.
- [Dropshare](dropshare.md) — File sharing tool for screenshots, screen recordings, and other files.
- [FileShipper](fileshipper.md) — Peer-to-peer file transfer between computers and phones over local Wi-Fi.
- [Flow](flow.md) — Award-winning, beautiful, fast, and reliable FTP + SFTP client.
- [LocalSend](localsend.md) — An open-source cross-platform alternative to AirDrop.
- [Nearby Drop](nearby-drop.md) — Independent macOS menu-bar app for two-way Google Quick Share transfers with compatible Android devices, plus USB MTP, Finder sharing, QR tools, and…
- [NearDrop](neardrop.md) — An unofficial Google Nearby Share/Quick Share app for macOS.
- [Rclone UI](rclone-ui.md) — The GUI for Rclone & S3.
- [Transmit](transmit.md) — Highly flexible and intuitive FTP client, supports SFTP, S3 and iDisk/WebDAV.
