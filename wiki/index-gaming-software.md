# Gaming Software

- [Bedrock Launcher](bedrock-launcher.md) — Play your own copy of Minecraft Bedrock Edition for Windows on Apple Silicon, fully offline, through a locally built WineGDK with DXMT.
- [Borne](borne.md) — Native front end for MAME and classic PC games (Doom, Quake, Duke Nukem 3D), in the spirit of MAMEUI, with the emulator and engines included.
- [ChessCafe](chesscafe.md) — Animated 3D chess with three AI levels, multiple armies, and hot-seat multiplayer.
- [Classic Game Box](classic-game-box.md) — Open-source retro-console emulator frontend built on libretro cores.
- [Highball](highball.md) — Run Windows games on Apple Silicon through Wine, with the graphics layer (DXMT, DXVK or D3DMetal) chosen per game from an open compatibility database.
- [OpenEmu](openemu.md) — Retro game emulator frontend for multiple console systems.
- [PlayCover](playcover.md) — Run iOS apps and games on Apple Silicon Macs with mouse, keyboard and controller support.
- [Porting Kit](porting-kit.md) — Install Windows® Games inside your Mac.
- [PPSSPP](ppsspp.md) — A awesome PSP emulator for any OS you can dream of!
- [RPCS3](rpcs3.md) — The Open-source PlayStation 3 Emulator
- [Ryubing](ryubing.md) — A fork of the discontinued Switch emulator, Ryujinx.
- [Suyu](suyu.md) — A familiar, open source, and powerful Nintendo Switch emulator.
- [Whisky](whisky.md) — A tool for running Windows apps on macOS, built with SwiftUI and supporting D3DMetal and DXVK backends.
- [ConsoleMini](consolemini.md) — Controller-first big-picture launcher that turns a Mac mini into a PS1-PS4 + retro console (wraps DuckStation, PCSX2, RPCS3, shadPS4, PPSSPP, RetroArch…
