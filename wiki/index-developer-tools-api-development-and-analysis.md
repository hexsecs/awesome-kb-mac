# Developer Tools / API Development and Analysis

- [bruno](bruno.md) — Bruno is a offline-only, fast and git-friendly opensource API client.
- [Cocoa Rest Client](cocoa-rest-client.md) — Free, open-source, native Apple OS X app for testing HTTP/REST endpoints.
- [Echolon](echolon.md) — Open-source API client and Postman alternative.
- [HTTPie](httpie.md) — HTTPie is making APIs simple and intuitive for those building the tools of our time.
- [Hoppscotch](hoppscotch.md) — A lightweight, fast, and full-featured API debugging tool.
- [Insomnia](insomnia.md) — The most intuitive cross-platform REST API Client.
- [Katalon Studio](katalon-studio.md) — Simplify API, Web, and Mobile Automation Tests.
- [Maestro](maestro.md) — End-to-end testing framework for mobile and web apps.
- [Mockoon](mockoon.md) — Create mock APIs in seconds.
- [Optics Framework](optics-framework.md) — Open-source UI test automation for Android, iOS, web and smart TV apps, with tests written as CSV or YAML steps.
- [Paw](paw.md) — Advanced HTTP client.
- [Postman](postman.md) — GUI platform for API development.
- [Reqable](reqable.md) — Next-Gen API Development Tool, Advanced API Debugging Proxy and REST Client.
- [ReqRes](reqres.md) — Native macOS app to monitor, debug, and mock HTTP(S) requests and responses.
- [Requestly](requestly.md) — Open-source, lightweight Git-Friendly API Client built for modern developers.
- [Trayce](trayce.md) — Lightweight tool to monitor Docker container traffic with a built-in .bru HTTP client.
- [Yaak](yaak.md) — A modern API client supporting multiple protocols, offline usage, and Git integration.
