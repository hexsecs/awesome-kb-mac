# Terminal Apps

- [alacritty](alacritty.md) — A cross-platform, GPU-accelerated terminal emulator.
- [Awal Terminal](awal-terminal.md) — AI-native terminal emulator with multi-provider profiles and voice input.
- [Calyx](calyx.md) — Native macOS terminal for running and supervising coding agents in parallel.
- [Command Book](command-book.md) — A terminal companion for long-running terminal commands (freemium)
- [electerm](electerm.md) — Terminal, SSH, and SFTP client.
- [Farol](farol.md) — Terminal built on libghostty that shows which coding agent is working, waiting or done.
- [Ghostty](ghostty.md) — Fast GPU-accelerated terminal emulator.
- [ghostty-designer](ghostty-designer.md) — Live-preview editor for Ghostty themes, fonts and UI settings.
- [hyper](hyper.md) — A terminal built on web technologies.
- [iTerm2](iterm2.md) — iTerm2 is an amazing terminal emulator for OS X.
- [kitty](kitty.md) — A cross-platform, fast, feature full, GPU based terminal emulator.
- [KubeSwitch](kubeswitch.md) — The fastest way to switch between Kubernetes contexts and namespaces on macOS.
- [SSHFire](sshfire.md) — Cross-platform SSH client with a terminal, a session manager and an SFTP browser that follows the current directory.
- [SSHTermaq](sshtermaq.md) — PuTTY-compatible SSH, Telnet and serial terminal with tabs, split panes, an SFTP/SCP file manager and one-click PuTTY session import.
- [Tabby (formerly Terminus)](tabby-formerly-terminus.md) — Free terminal tool, built with TypeScript, heavily inspired by Hyper.
- [Termius](termius.md) — A beautiful SSH and SFTP client for Mac. It is also available for mobile.
- [Termstead](termstead.md) — Native SSH client with a session tree, jump hosts and SFTP beside the terminal.
- [tty7](tty7.md) — A GPU-rendered, daemon-backed terminal in pure Rust with sessions that stay alive without tmux.
- [Vesta](vesta.md) — Native macOS terminal built on libghostty for running coding agents in parallel.
- [Warp](warp.md) — Warp is a blazingly fast, rust-based terminal reimagined from the ground up to work like a modern app.
- [Wave](wave.md) — Open-source terminal with built-in file previews, web browsing, and AI tools.
- [WezTerm](wezterm.md) — A GPU-accelerated cross-platform terminal emulator and multiplexer implemented in Rust.
