# Proxy and VPN Tools

- [Algo](algo.md) — Personal IPSEC VPN in the cloud.
- [ClashBar](clashbar.md) — mihomo-powered menu bar proxy client.
- [ClashX Guide](clashx-guide.md) — Guides and troubleshooting tools for ClashX.
- [Cloudflare WARP](cloudflare-warp.md) — Secure network service that routes traffic through Cloudflare.
- [DashVPN](dashvpn.md) — Smart-routing proxy client with support for VLESS, Shadowsocks, and HTTPS subscriptions.
- [Hiddify](hiddify.md) — Multi-platform proxy client for managing subscriptions and multiple proxy protocols.
- [Jumper VPN](jumper-vpn.md) — VPN Client for Mac and other platforms, secure, fast VPN proxy.
- [Lantern](lantern.md) — Free application that delivers fast, reliable and secure access to the open internet.
- [Mullvad VPN](mullvad-vpn.md) — Privacy-focused VPN service with anonymous accounts and flat-rate access.
- [Outline](outline.md) — Outline makes it easy to create a VPN server, giving anyone access to the free and open internet.
- [RerouteMe](rerouteme.md) — An easy one-click macOS Proxy Configuration app.
- [ShadowsocksX-NG](shadowsocksx-ng.md) — Next generation of ShadowsocksX.
- [ShadowsocksX](shadowsocksx.md) — Secure socks5 proxy, designed to protect your internet traffic.
- [Shimo](shimo.md) — VPN Client for Mac.
- [SpechtLite](spechtlite.md) — Rule-based proxy app for macOS.
- [Surge](surge.md) — Web developer tool and proxy utility for iOS 9.
- [tinc](tinc.md) — Secure mesh VPN software.
- [TrustTunnel](trusttunnel.md) — A modern, open-source VPN protocol originally developed by AdGuard VPN.
- [Tunnelbear](tunnelbear.md) — Simple VPN service for secure browsing and location switching.
- [Tunnelblick](tunnelblick.md) — Free, open-source graphic user interface for OpenVPN on OS X.
- [VPN Bypass](vpn-bypass.md) — Menu bar app to route specific domains and services around your VPN.
- [Windscribe](windscribe.md) — VPN and proxy service with ad blocking and flexible server switching.
- [Tailscale](tailscale.md) — Mesh VPN for securely connecting devices, services, and users.
