# Utilities / Clipboard Tools

- [Buffer](buffer.md) — Lightweight native clipboard manager with bookmarks and OCR for images.
- [CleanClip](cleanclip.md) — The cleanest Clipboard Manager on macOS, ever!

- [ClipTools](cliptools.md) — Clipboard utility set for quick copy, paste, and text cleanup tasks.

- [Whisk](whisk.md) — Keyboard-first clipboard manager with a Liquid Glass panel, filters by source app and content type, and rich previews.
